# 第四章 交互与渲染设计（v0.1 草案）

> 覆盖：图层渲染规范（含你要求的边界线型/颜色、门旗标语义）、区块编辑（圈地）、门编辑（打孔/吸附/表单）、常送点快采、视觉反馈与手势精度。

## 1. 地图图层顺序（自底向上）

```
1  底图瓦片（OSM，离线缓存）
2  区块蒙层填充（半透明色块，含 hatch 纹理选项）
3  区块边界线（按 boundary_type 线型/颜色，粗线）
4  路由底网线（M2 后淡显：骑行=蓝、推行=紫、步行=绿）  [浏览模式]
5  常送点/实体图标（按 entity_type）
6  门旗标（状态色圆点/旗帜，按当前时间推导）
7  选中高亮（编辑态：正在编辑的边界高亮、吸附点光标）
8  编辑交互层（触控捕获：点击/长按/拖动坐标换算）
9  顶部 HUD：当前模式提示、缩放按钮、定位按钮、保存/取消
10 底部面板：区块/门/实体详情或表单（半屏）
```

## 2. 区块边界可视化规范（按你原稿细化）

| boundary_type | 颜色 | 线型 | 蒙层填充 | 说明 |
|---------------|------|------|----------|------|
| `wall` 实体墙 | 红 `#D32F2F` | 实线、粗(6px) | 红灰半透明(≤25%) | 完全不可通行 |
| `fence` 铁栅栏 | 红 `#E57373` | 虚线 | 同上 | 看得见过不去 |
| `hedge` 绿化带 | 绿 `#66BB6A` | 绿虚线 | 绿灰半透明 | 矮灌木可考虑，但默认仍不可穿 |
| `river` 河道/水渠 | 蓝 `#29B6F6` | 实线 | 蓝灰半透明 | 物理不可穿 |
| `construction` 施工围挡 | 橙 `#FFA726` | 斜纹(hatch) | 橙灰半透明 | 附带拆除日期提示，可临时关闭 |
| `none` 软边界(可选) | 灰 `#9E9E9E` | 点线 | 极淡 | 只做语义分区不阻断（如城中村整体范围） |

边界线**总宽于**底图道路，编辑态选中为高亮黄/白 4px 外描边。

## 3. 门旗标可视化（实时状态色）

| 门状态（由 gate_time 引擎推导） | 旗标 | 附加文案 |
|-------------------------------|------|---------|
| 当前开放且我可通行 | 绿色小旗 | “可进” |
| 当前关闭 / 未到开放时段 | 红色小旗 | “XX:XX 开放” |
| 当前开放但需登记/刷卡/人脸 | 黄色感叹号旗 | “需登记/刷卡/人脸” |
| 车型不符（我只骑电动车，该门禁 car only） | 灰色× | “禁电动车” |
| 门已失效(临时关闭/施工) | 灰色空心 | “临时关闭” |

> 状态 = 函数 `f(gate, now, my_vehicle=ev_bike)`，任何时候一致渲染（列表、地图、详情同源）。

## 4. 区块编辑（圈地）交互流程

### 4.1 新建区块流程

1. 进入浏览模式，点工具栏「＋ 区块」→ 进入 **区块绘制模式**（地图顶部出现模式条：`打点中(可撤销) · 完成 · 取消`）。
2. **打点画多边形**：单指点按 → 在当前坐标落点（吸附规则见 §7）；点按已画第一点附近（< 容差）或双击末点 → 自动闭合。
3. 连续绘制时预览线为半透明描边；支持 **点击最后一个点=回退一锚点**（撤销最近一个点）。
4. 闭合后自动进入 **属性确认面板（半屏）**：
   - 名称（必填）、boundary_type 选择器（含色样预览）、boundary_height 文本、is_active 开关、（construction 时）拆除日期；
   - 确认 → 落库并生成 `lines(kind=area_boundary)` 环；取消 → 丢弃本次草稿。
5. 保存后仍处于"选中该区块"状态，可立刻添加门。

### 4.2 编辑已有区块

- 点击区块内部 → 高亮选中 → 底部面板：[添加门] [编辑边界] [属性] [删除]。
- **编辑边界**：进入边界编辑模式，顶点显示为可拖圆形手柄；
  - 拖顶点：实时更新相邻边界线与依附于该线段上的门位置（联动吸附，见 §6）；
  - 点选线段中点 → 插入新顶点（细化边界）；
  - 顶点上滑/长按菜单 → 删除该顶点（少于 3 个顶点时禁止）；
  - 完成 → 校验闭合与门吸附有效性。

## 5. 门编辑（打孔）交互流程

### 5.1 新建门

1. 选中区块后点「添加门」或在区块绘制完成后直接进入 **门打孔模式**。
2. 点按边界线（**必须在线上或近线**）→ 落点自动**吸附到最近 boundary_line 的垂足**，绘制"十字 + 吸附圆"光标提示已捕捉；吸附容差默认 12px（约 3–8 米随缩放变化）。
3. 落点后弹出 **门属性表单（下半屏）**，字段（对应 03 章 gates 表）：
   - 名称（如"北门（正门）"）；
   - vehicle_type 单选（默认 `ev_bike`）；
   - access_level 单选（free/guard/swipe_card/face_recognition）；
   - 开放时间窗编辑器：时间窗列表 [开始/结束]，MVP 支持按天整体一致；`每周固定时段` UI 用 7 天 tab 预留（Q-07）；
   - has_stairs、entry_only、is_permanent、is_active 开关；
   - 备注。
4. 保存 → gate 落库；地图渲染旗标（此时按当前时间显示状态）。
5. 底部面板含 **[重定位]**（长按拖动微调门位置）入口。

### 5.2 微调 / 编辑门

- **拖动微调**：长按门旗标 → 进入微调态 → 沿边界线滑动（自动**沿线吸附**，不允许拖离线外）→ 松手保存新位置。
- 点击门旗标 → 详情面板（含状态、时间窗摘要、编辑/删除按钮）。
- 边界被编辑导致门偏移超容差 → 列表给出"门已离线"警告，一键重新吸附。

## 6. 边界编辑与门联动规则

- 门引用 `boundary_line_id + line_weight`，**位置永远由线推导**；
- 拖顶点/增删顶点 → 相关门自动重算 location（几何模块 `reprojectOnLine`）；
- 因此区块几何以 **lines+points 为唯一事实源**，渲染层不直接存多边形副本（03 章 Q-01 已待确认）。

## 7. 手势、吸附与精度

| 手势 | 行为 | 吸附 |
|------|------|------|
| 单击 | 依当前模式：落点/选中/打开 | 点吸附优先(现有顶点/门)，其次线吸附(垂足) |
| 长按门旗标 | 进入微调 | 强制沿线吸附 |
| 拖动顶点 | 移动该点 | 就近顶点吸附(合并点，可选) |
| 双击末点 | 闭合多边形 | — |
| 双指 | 缩放/平移（flutter_map 原生） | — |
| 撤销/重做 | 编辑栈（区域级草稿 + 全局最近 N 步） | — |

精度控制：

- 打点容差 / 吸附容差随 zoom 换算为米（保证远缩时不吸附到邻线）；
- 绘制中顶部显示当前落点经纬度与与起点的距离（便于"沿围墙走一圈"对齐真实边界）；
- 提供「对准 GPS」按钮（快采时用当前定位自动落点，见 §8）。

## 8. 常送点 / 实体快采（路过即记）

场景 U6（路过即记）是数据增长的入口，须**三步内完成**：

1. 地图右上「定位」键旁边常驻「＋点」快捷键；或在实体模式点按地图空白处 → “新建实体”。
2. 自动带出当前 GPS 坐标（`accuracy` 一并记录）；可拖拽微调位置/吸附到线上。
3. 表单：名称（默认自动编号"新常送点#n"）、entity_type（常送点/楼栋/档口/停车点…）、可选绑定到最近巷线、tags（楼层/门牌/备注/照片）。

> 快捷：文本输入带历史联想；与"该点属于哪个区块/最近哪个门"联动建议（geo 反查自动填充候选）。

## 9. 列表视图（非地图入口）

- **区块列表**：名称/类型色条/门数量/状态摘要；搜索过滤；新建入口。
- **门列表（按区块分组）**：名称/时间窗摘要/当前状态色点/编辑。
- **实体/常送点列表**：按 entity_type 过滤、按最近使用排序；点击定位到地图。
- 以上列表与地图选中双向联动。

## 10. 主题与文案基调

- 深色底图夜间模式可选（骑手常夜班），区块蒙层透明度在夜间提高对比；
- 文案简洁中文；“可进/已关/需登记”等旗标文案为主动词；
- 所有破坏性操作（删除区块/清空）需二次确认并可撤销。
